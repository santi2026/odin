Formatos y conversiones

JSON conserva objetos, arrays y tipos nativos.

CSV representa una tabla. Los arrays y objetos de una celda se escriben como JSON; varias tablas se descargan en un ZIP.

XML de ODÍN incluye metadatos de tipo para poder abrirse de nuevo sin pérdidas.

XML externo se adapta: atributos en @attributes, texto en #text y etiquetas repetidas como arrays. Se solicita confirmación antes de abrirlo.
